사용법

AI에게 받은 수식을 한글 문서에 넣기까지의 과정을 기능별로 정리했습니다. 보고서에 수식 몇 개만 넣을 때는 ‘수식 변환’을, 답변 전체를 문서로 옮길 때는 ‘마크다운 → HWPX’나 크롬 확장을 쓰면 됩니다.

시작 전에: AI에게 수식을 LaTeX로 받기

ChatGPT, Claude, Gemini 같은 AI는 수식을 LaTeX라는 문법으로 씁니다. 화면에는 예쁘게 그려져 보이지만, 그려진 수식을 마우스로 긁어 복사하면 위·아래 첨자와 분수 구조가 사라진 글자만 남습니다. 휩이 정확하게 변환하려면 그림이 아닌 LaTeX 원문이 필요합니다.

원문을 얻는 가장 쉬운 방법은 AI에게 처음부터 이렇게 부탁하는 것입니다.

답변에서 수식은 렌더링 하지 말고 순수 LaTeX 코드로 작성해 줘. 복사 가능하도록 latex 코드 블록을 사용해 줘.

이미 받은 답변이라면 AI 답변 아래의 복사 버튼을 쓰세요. ChatGPT·Claude·Gemini의 답변 복사 버튼은 대부분 수식을 $$ … $$ 형태의 LaTeX로 복사해 줍니다. 크롬 확장을 설치하면 수식 위에 마우스를 올리는 것만으로 원문을 읽어 와 변환해 줍니다.

LaTeX는 보통 $$ … $$, $ … $, \[ … \], \( … \) 같은 기호로 감싸져 있습니다. 휩은 이 기호를 알아서 떼어 내고 안쪽 수식만 변환합니다. 감싸는 기호 없이 \frac{dp}{dx}처럼 명령어만 있어도 변환은 되지만, 어디까지가 수식인지 헷갈릴 수 있어 경고를 띄웁니다.

수식 변환

메인 화면의 수식 변환 탭이 휩의 기본 기능입니다. 수식 하나를 한글 수식 편집기 문법으로 바꿉니다.

  1. AI 답변에서 수식의 LaTeX를 복사합니다. 예: $$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
  2. 변환기의 LaTeX 입력창에 붙여넣습니다. 따로 버튼을 누를 필요 없이 입력하는 즉시 변환됩니다.
  3. 아래 한글 수식 칸에 결과가 나타나고 자동으로 클립보드에 복사됩니다. 다시 복사하려면 복사 버튼을 누르세요.
  4. 맨 아래 미리보기에서 수식이 의도대로 그려지는지 확인합니다. 미리보기는 입력한 LaTeX를 그린 것이라, 원문이 잘못됐는지 확인할 때 유용합니다.

위 예시는 이렇게 바뀝니다.

x `=` {`-` b plusminus sqrt {b ^{2} `-` 4 a c}} over {2 a}

결과 읽는 법

한글 수식 문법은 LaTeX와 모양이 다릅니다. 분수는 {분자} over {분모}, 제곱근은 sqrt, ±는 plusminus처럼 영어 낱말을 씁니다. 결과 곳곳의 `(백틱)은 1/4 크기 빈칸으로, 등호·더하기 주변을 보기 좋게 띄우는 역할입니다. 공백 기호 강조를 켜면 이런 간격 기호와 구조 명령이 색으로 구분되어 보입니다. 복사되는 내용은 똑같습니다. 문법이 궁금하다면 한글 수식 문법 페이지를 참고하세요.

한 번에 수식 하나씩

입력창에 수식을 여러 개 넣으면 하나의 긴 수식으로 합쳐집니다. 한글에서는 수식 개체 하나에 수식 하나를 넣는 것이 보통이므로, 수식마다 따로 변환해 붙여넣으세요. 수식이 많은 답변을 통째로 옮기려면 아래의 마크다운 → HWPX가 훨씬 빠릅니다.

“렌더링된 수식을 붙여넣은 것 같다”는 경고가 뜰 때

AI 화면에 그려진 수식을 마우스로 긁어 복사하면 x2처럼 첨자가 평범한 글자로 바뀌어 붙습니다. 휩이 이런 흔적을 발견하면 경고 창을 띄우고 세 가지 해결 방법을 안내합니다.

  • AI에게 LaTeX 원문으로 다시 써 달라고 요청하기 (위 시작 전에의 문장)
  • 수식을 캡처해서 이미지에서 인식으로 읽기
  • 크롬 확장으로 원문을 직접 가져오기

한글에 붙여넣기

변환된 결과는 한글 본문에 그대로 붙이는 것이 아니라 수식 편집기 안에 붙여넣어야 수식으로 그려집니다.

  1. 한글 문서에서 수식을 넣을 위치에 커서를 둡니다.
  2. 입력 → 개체 → 수식 메뉴를 열거나 단축키 Ctrl+N, M을 누릅니다.
  3. 수식 편집기 아래쪽의 글자 입력 칸을 클릭하고 Ctrl+V로 붙여넣습니다. 위쪽 미리보기에 수식이 바로 그려집니다.
  4. 넣기를 누르면 문서에 수식 개체가 들어갑니다.

수식 편집기의 메뉴 위치와 단축키는 한글 버전에 따라 조금 다를 수 있습니다. 중요한 것은 결과를 수식 편집기의 입력 칸에 붙인다는 점입니다. Windows에서는 보조 프로그램을 설치하면 이 과정 없이 본문에 바로 수식 개체로 붙일 수 있습니다.

이미지에서 인식

교과서, 논문 PDF, 캡처 화면처럼 LaTeX 원문이 없는 수식은 이미지로 읽을 수 있습니다. 수식 변환 탭에서 세 가지 방법 중 편한 것을 쓰세요.

  • 입력창 오른쪽 위의 이미지에서 인식 버튼을 눌러 이미지 파일 고르기
  • 이미지 파일을 입력창 위로 끌어다 놓기
  • 수식을 캡처한 뒤 입력창에 Ctrl+V(맥은 ⌘+V)로 바로 붙여넣기

인식된 LaTeX가 입력창에 들어가고, 이후는 일반 수식 변환과 똑같이 한글 수식으로 바뀌어 복사됩니다.

알아 둘 점

  • 처음 한 번은 시간이 걸립니다. 수식 인식 AI 모델을 브라우저로 내려받기 때문입니다. 한 번 받은 모델은 브라우저에 보관되어 다음부터는 빨라집니다.
  • 이미지는 밖으로 나가지 않습니다. 인식은 서버가 아니라 내 브라우저 안에서 실행됩니다.
  • 수식 부분만 잘라서 넣을수록 정확합니다. 글과 수식이 섞인 큰 캡처보다 수식 하나만 캡처하세요.
  • 인식이 완벽하지 않을 수 있으니 미리보기로 원본과 비교하고, 틀린 부분은 입력창의 LaTeX를 직접 고치세요.

HWP·HWPX 문서 변환

이미 한글 문서에 $x^2$ 같은 LaTeX 글자가 잔뜩 들어가 있다면, 하나하나 고칠 필요 없이 문서 전체를 한 번에 바꿀 수 있습니다.

  1. 메인 화면에서 문서 변환 탭을 엽니다.
  2. .hwpx 또는 .hwp 파일을 끌어다 놓거나 파일 선택을 누릅니다.
  3. 문서 안의 LaTeX 구간이 한글 수식 개체로 바뀐 새 .hwpx 파일이 만들어집니다. 바꾼 수식 개수와 그대로 둔 금액 표기 개수가 함께 표시됩니다.
  4. 파일 이름을 정하고 내려받아 한글에서 엽니다.

알아 둘 점

  • 결과는 항상 HWPX입니다. HWP 파일이 필요하면 한글에서 열어 ‘다른 이름으로 저장’으로 HWP를 고르세요.
  • HWP 파일은 인터넷이 필요합니다. HWP는 이진 형식이라 오픈소스 엔진 rhwp를 불러와 HWPX로 바꾼 다음 변환합니다. HWPX는 오프라인에서도 됩니다.
  • $100$처럼 숫자만 있는 달러 표기는 금액으로 보고 건드리지 않습니다.
  • 감싸는 기호 없이 \frac 같은 명령어만 있는 글도 수식으로 바꾸며, 이렇게 바꾼 개수가 있으면 따로 알려 줍니다. 결과 문서에서 그 부분을 한 번 확인해 보세요.
  • 파일은 내 브라우저 안에서만 처리되고 서버에 올라가지 않습니다.

마크다운 → HWPX

AI가 써 준 보고서 초안을 통째로 한글 문서로 만드는 기능입니다. 제목, 목록, 표, 코드, 수식이 한글 서식과 수식 개체로 들어갑니다.

  1. AI 답변 아래의 복사 버튼으로 답변 전체를 복사합니다. 대부분의 AI는 이 버튼으로 마크다운 형식을 복사해 줍니다.
  2. 메인 화면에서 문서 변환 탭을 열고 Ctrl+V(맥은 ⌘+V)로 붙여넣습니다. .md 파일이 있다면 파일을 올려도 됩니다.
  3. 문서 설정에서 본문 글꼴, 글자 크기, 파일 이름을 정합니다. 내 PC에 설치된 글꼴 불러오기를 누르면 컴퓨터에 깔린 글꼴도 고를 수 있습니다(Chrome·Edge).
  4. 오른쪽 A4 미리보기로 모양을 확인한 뒤 다운로드 버튼을 누릅니다.

크롬 확장

AI 답변 화면을 떠나지 않고 바로 변환하고 싶다면 휩 크롬 확장을 설치하세요. 크롬 웹 스토어에서 설치합니다.

수식 위에 마우스만 올리면 복사

AI 답변의 수식에 마우스를 올리면 HWP 복사 버튼이 나타납니다. 누르면 한글 수식으로 바뀌어 클립보드에 들어가므로, 한글 수식 편집기에 바로 붙여넣으면 됩니다. 화면에 그려진 수식이 아니라 원본 LaTeX를 읽어 오기 때문에 첨자가 사라지지 않습니다.

긴 답변은 HWPX 문서로

보고서처럼 긴 답변 아래에는 hwpx파일로 버튼이 나타납니다. 누르면 옆에 사이드패널이 열리고, 글꼴·글자 크기·파일 이름을 정하고 A4 미리보기를 본 다음 .hwpx로 내려받을 수 있습니다.

직접 입력

브라우저 툴바의 휩 아이콘을 누르면 작은 창에서 LaTeX를 입력해 바로 변환할 수 있습니다.

지원 사이트

ChatGPT, Claude, Gemini, Google AI Studio, Perplexity, Grok, DeepSeek, Poe 등 주요 AI 사이트에서 설정 없이 동작합니다. 목록에 없는 사이트는 확장 아이콘을 눌러 이 페이지에서 켜기로 직접 켤 수 있습니다.

Windows: 수식 개체로 바로 붙여넣기

Windows에서 설치형 한글을 쓴다면 보조 프로그램을 함께 설치해, 수식 편집기를 열지 않고 한글 본문에 Ctrl+V만으로 편집 가능한 수식 개체를 넣을 수 있습니다. 글과 수식이 섞인 문단을 통째로 복사하면 글은 본문으로, 수식은 각각 수식 개체로 붙습니다.

  1. HwipCompanion.exe를 내려받아 실행하고 예를 눌러 설치합니다. 관리자 권한은 필요 없고, Windows를 켤 때 자동으로 실행되어 작업 표시줄 알림 영역에 머뭅니다.
  2. 확장 아이콘을 눌러 설정의 Windows 수식 개체 변환을 켜고, 이어서 뜨는 권한 요청을 허용합니다. 확장이 보조 프로그램을 찾은 경우에만 켜지고, 찾지 못하면 다시 꺼지며 내려받기 링크가 나타납니다. 상태가 Windows 프로그램 연결됨으로 바뀌면 준비가 끝난 것입니다.
  3. AI 답변에서 수식의 HWP 복사 버튼을 누르거나, 글과 수식이 섞인 부분을 드래그해 Ctrl+C를 누릅니다. 변환이 끝나면 알림이 뜹니다.
  4. 한글 본문에서 Ctrl+V를 누릅니다.

보조 프로그램에는 코드 서명이 없어 처음 실행할 때 “Windows의 PC 보호” 창이 뜰 수 있습니다. 추가 정보 → 실행을 누르세요. 소스와 빌드 과정은 GitHub에 공개되어 있습니다. 이 기능은 직접 켰을 때만 동작하며, 꺼 두면 확장은 지금과 똑같이 한글 수식 문자열을 복사합니다. 메모장 같은 다른 프로그램에 붙이면 원래 복사한 글이 그대로 들어갑니다.

자주 묻는 질문

무료인가요?

네. 웹 버전, 크롬 확장 모두 무료이고 회원가입도 없습니다. 소스 코드는 GitHub에 공개되어 있습니다.

제가 넣은 수식이나 문서가 서버에 저장되나요?

웹 버전의 수식 변환, 이미지 인식, 문서 변환은 모두 내 브라우저 안에서 처리되어 서버로 보내지 않습니다. 크롬 확장의 HWP 복사 버튼만 수식 텍스트를 변환 서버로 보내며, 저장하지 않습니다. Windows 보조 프로그램은 내 PC 안에서만 동작합니다. 자세한 내용은 개인정보처리방침에 있습니다.

인터넷이 끊겨도 쓸 수 있나요?

한 번 접속한 브라우저라면 수식 변환과 HWPX·마크다운 변환은 오프라인에서도 됩니다. 이미지 인식은 모델을 한 번 내려받은 뒤라면 동작하고, HWP 파일 변환은 인터넷이 필요합니다.

변환 결과가 이상하게 그려져요.

먼저 미리보기에서 입력한 LaTeX가 맞는지 확인하세요. 원문이 맞는데 한글에서 다르게 그려진다면, 입력한 LaTeX와 결과를 문의나 GitHub Issues로 알려 주세요. 휩이 모르는 명령어는 지우지 않고 그대로 남겨 두므로, 결과에 \로 시작하는 낱말이 보이면 아직 지원하지 않는 명령어입니다.

한글 수식 문법을 직접 배우고 싶어요.

한글 수식 문법 페이지에 분수, 첨자, 행렬부터 기호 이름까지 정리해 두었습니다. 자주 쓰는 수식은 변환 예시에서 바로 복사할 수 있습니다.

프로그램에서 변환 기능을 쓰고 싶어요.

POST https://hwip.dshs.dev/api/convert에 {"latex": "…"}를 보내면 {"result": "…"}로 한글 수식을 돌려받는 API를 제공합니다.
