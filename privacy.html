개인정보 처리방침

휩은 회원가입이 없고 개인정보를 수집하지 않습니다. 어떤 데이터가 어디로 가는지 아래에 그대로 밝힙니다.

시행일: 2026년 10월 16일

휩 - AI to 한글(HWP)(이하 "휩")은 크롬 확장 프로그램, 웹 서비스(hwip.dshs.dev), 변환 API로 구성됩니다. 휩은 회원가입·로그인이 없으며, 이름·이메일 같은 개인정보를 수집하지 않습니다. 아래에서 어떤 데이터가 어디로 가는지 그대로 밝힙니다.

1. 한눈에 보기

  • 서버로 전송되는 것은 단 하나: 크롬 확장의 "HWP 복사" 버튼과 확장 팝업에서 변환하는 수식(LaTeX) 텍스트가 변환을 위해 https://hwip.dshs.dev/api/convert 로 전송됩니다(HTTPS).
  • AI 답변 본문, 대화 내용, 이미지, 파일은 서버로 전송되지 않습니다.
  • 보고서→HWPX 변환, 파일 변환, 이미지 OCR, Markdown→HWPX는 모두 사용자의 브라우저 안에서 처리됩니다.
  • 사용자 데이터를 판매하거나 광고·프로파일링에 사용하지 않으며, 제3자에게 제공하지 않습니다.

2. 크롬 확장 프로그램

2-1. 읽는 정보와 처리 방식

  • 웹페이지 콘텐츠: 지원되는 AI 사이트에서 화면에 렌더된 수식과 답변 본문을 읽어, 수식 위에 복사 버튼을 표시하고 보고서 변환 버튼을 표시합니다. 이 읽기는 브라우저 안에서만 일어나며 저장되지 않습니다.
  • 수식 변환 요청: 변환할 수식 텍스트(LaTeX 문자열)만 위 API로 전송하고, 변환된 한글 수식 문자열을 응답으로 받습니다. 쿠키·계정 정보·답변의 다른 부분은 전송하지 않습니다(다만 브라우저가 모든 요청에 자동으로 붙이는 기본 헤더, 예를 들어 요청을 보낸 사이트의 도메인 등은 함께 전달될 수 있습니다). 휩의 서비스 코드는 요청 내용을 저장하거나 기록하지 않습니다. 다만 호스팅 플랫폼(Vercel)이 서비스 운영을 위해 접속 IP 등 일반적인 서버 로그를 일정 기간 보관할 수 있습니다.
  • 보고서 → HWPX: 답변 본문은 브라우저 안에서 마크다운으로 바뀌어 확장의 사이드패널로 전달되고, 그곳에서 HWPX 파일로 만들어집니다. 이 과정에서 서버로 전송되지 않습니다. 사이드패널 미리보기의 수식 스타일(KaTeX CSS)은 cdn.jsdelivr.net 에서 불러오므로, 이 요청에는 CDN 운영사가 일반적으로 보는 접속 정보(IP 등)가 포함됩니다.
  • 저장되는 정보: chrome.storage.sync 에 기능 켜기/끄기 설정이, chrome.storage.local 에 선택한 글꼴 설정이 저장됩니다. 보고서 변환 시 추출한 마크다운은 사이드패널에 전달된 직후 삭제되는 임시 값입니다. 동기화 설정은 사용자의 Google 계정을 통해 Chrome이 동기화할 수 있습니다.

2-2. 권한 사용 안내

아래 권한은 명시된 목적에만 사용됩니다.

  • 호스트 권한 (ChatGPT, Claude, Gemini, Google AI Studio, Perplexity, Grok, DeepSeek, Poe 등 지원 사이트): 해당 사이트의 응답에서 수식·본문을 읽고 변환 버튼을 표시하기 위해 사용합니다.
  • 호스트 권한 https://hwip.dshs.dev/*: 수식 변환 API 호출에 사용합니다.
  • clipboardWrite: 변환된 한글 수식을 클립보드에 복사합니다.
  • clipboardRead: Google AI Studio의 "Copy as markdown" 결과를 읽어 보고서 변환에 사용합니다. 읽은 내용은 서버로 전송되지 않습니다.
  • storage: 위 2-1에 적은 설정 저장과 사이드패널로의 임시 전달에 사용합니다.
  • sidePanel: HWPX 변환 설정·미리보기·다운로드 화면을 표시합니다.
  • scripting / activeTab: 사용자가 팝업에서 "이 페이지에서 켜기"를 눌렀을 때에 한해 해당 탭에 스크립트를 주입합니다.
  • 선택적 호스트 권한 (모든 사이트, 로컬 파일): 지원 목록에 없는 페이지나 로컬 파일에서 사용자가 직접 기능을 켤 때에만 요청합니다. 켜기 전에는 해당 페이지에서 아무 것도 읽지 않습니다.

3. 웹 서비스 (hwip.dshs.dev)

  • 수식 변환, 이미지 OCR, 파일(HWP/HWPX) 변환, Markdown→HWPX: 모두 접속자의 브라우저 안에서 처리되며 입력한 텍스트·이미지·파일이 휩 서버로 전송되거나 저장되지 않습니다.
  • 외부에서 불러오는 리소스: 수식 렌더링·마크다운 라이브러리는 cdn.jsdelivr.net 에서, 이미지 OCR 모델은 최초 사용 시 Hugging Face에서 내려받아 브라우저에 보관합니다. HWP(이진) 파일을 변환할 때는 오픈소스 rhwp 편집기 페이지(edwardkim.github.io)를 화면에 보이지 않게 불러와 변환에 사용합니다(인터넷 연결 필요). 이 요청에는 해당 서비스 운영사가 일반적으로 보는 접속 정보(IP 등)가 포함됩니다.
  • 방문 통계: 서비스 개선을 위해 Vercel Web Analytics를 사용합니다. 쿠키 없이 페이지 조회, 유입 경로, 브라우저·기기 종류, 국가 수준 위치 같은 집계 정보만 수집하며 개인을 식별하지 않습니다.
  • 저장: 테마(라이트/다크) 같은 화면 설정은 브라우저의 localStorage에만 저장됩니다.

4. 변환 API

POST https://hwip.dshs.dev/api/convert 는 받은 LaTeX 문자열을 변환해 결과만 돌려주며, 서비스 코드는 요청 내용을 저장하지 않습니다. 호스팅 플랫폼의 일반 서버 로그(IP 등)는 위 2-1과 같이 남을 수 있습니다.

5. 제3자 제공 및 사용 제한

휩은 사용자 데이터를 판매하지 않고, 광고·신용 평가·프로파일링 목적으로 사용하거나 제3자에게 이전하지 않습니다. 휩의 사용자 데이터 사용은 제한적 사용(Limited Use) 요구사항을 포함한 Chrome 웹 스토어 사용자 데이터 정책을 준수합니다. 위에 적은 인프라·CDN 사업자(Vercel, jsDelivr, Hugging Face, GitHub Pages)는 서비스 제공 과정에서 접속 정보를 처리할 수 있으며, 각 사업자의 정책이 적용됩니다.
